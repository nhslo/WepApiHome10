# Домашнее задание 10 — учёт книг и читателей

## Краткий отчёт

Консольная программа ведёт книги, читателей и выдачи в памяти.

## Выполнение по заданию

### 1. Данные

Использованы структуры `Book`, `Reader`, `Loan` и срезы для их хранения. Карта связывает ID книги с позицией, вторая карта хранит активные выдачи читателей.

### 2. Операции

Меню позволяет добавить книгу и читателя, выдать и вернуть книгу, найти книгу и показать книги читателя. Выдача уменьшает количество, возврат увеличивает его. Повторный возврат, неверный ID и выдача без экземпляров отклоняются.

### 3. Статистика

Показываются количество названий и экземпляров, доступные и выданные книги, самая популярная книга. Массив дней недели используется в заголовке отчёта.

## Запуск

```powershell
go run .
```

Введите данные по пунктам меню. Данные существуют до закрытия программы.

## Вывод

Срезы хранят записи, карты помогают искать книги и активные выдачи, а указатель меняет количество экземпляров.
